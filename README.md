# Terminal Chatbot

A simple Python terminal chatbot named Jarvis.

I worked as a junior developer in 2022–2023, but after a year (2025 to 2026) of relying heavily on AI, I’m rebuilding my fundamentals and confidence writing code independently.

This chatbot starts with predefined responses, with my local Ollama integration planned.

## What I'm Practicing

- Variables, strings, and basic data types
- User input and terminal output
- Conditions using if, elif, and else
- Loops, break, and continue
- Cleaning input with strip() and lower()
- Formatting output with f-strings
- Functions, parameters, and return values
- Lists and dictionaries for conversation history
- Organizing code into modules
- Virtual environments and dependencies
- Handling errors with try and except
- Reading and writing files to save conversations
- Working with JSON and HTTP requests
- Connecting to my local Ollama server
- Sending conversation history to an AI model
- Displaying streamed AI responses
- Debugging and testing program behavior
- Version control with Git and GitHub

## How to Run

With Python installed:

python chatbot.py

Type quit to exit.
